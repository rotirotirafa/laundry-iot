Laundry IoT

Guia de Operação — Sistema de Lavanderia Automatizada

Versão 1.0  ·  2026

Visão Geral do Sistema

O Laundry IoT é uma plataforma web para automação de lavanderias em condomínios. Inquilinos fazem login pelo número do apartamento, utilizam créditos para acionar máquinas de lavar e secar, que são controladas remotamente por tomadas inteligentes Sonoff com firmware Tasmota.

Pré-requisito: Docker e Docker Compose instalados na máquina servidora. Todos os comandos abaixo são executados no terminal, dentro da pasta do projeto.

Como Usar os Comandos (Makefile)

Todos os comandos são executados no terminal com o prefixo make, dentro da pasta raiz do projeto. Para ver a lista completa a qualquer momento:

$ make

Controle do Sistema

Estes comandos iniciam, param ou inspecionam toda a aplicação (banco de dados + servidor web).

ComandoO que faz
make ligar-sistema Inicia todos os serviços em segundo plano. A aplicação ficará disponível em http://localhost:8000
make desligar-sistema Para todos os containers. Os dados no banco de dados são preservados.
make reiniciar-sistema Reinicia os containers sem apagar dados (útil após mudanças de configuração).
make status-sistema Exibe o estado dos containers e os últimos 20 registros de log.
make logs Acompanha os logs em tempo real. Pressione Ctrl+C para sair.

Exemplo — subir o sistema pela primeira vez:

$ make ligar-sistema Iniciando o sistema... [+] Running 2/2 ✔ Container postgres_db Started ✔ Container laundry_iot_app Started Sistema iniciado. Acesse http://localhost:8000

Controle das Máquinas

Os comandos de máquina se comunicam diretamente com as tomadas Sonoff via rede local. Todos exigem o parâmetro ip= com o endereço IP da tomada.

Atenção: O computador onde o comando é executado deve estar na mesma rede Wi-Fi que as tomadas Sonoff. Verifique os IPs no painel do roteador ou no admin do sistema.
ComandoParâmetrosO que faz
make ligar ip= Liga a máquina imediatamente, sem timer.
make desligar ip= Desliga a máquina imediatamente.
make alternar ip= Inverte o estado atual (se ligada, desliga; se desligada, liga).
make status-maquina ip= Consulta e exibe o status atual da tomada (ligada/desligada, tensão, etc.).
make ligar-com-timer ip= minutos= Liga a máquina e programa o desligamento automático após N minutos. Mesmo que o sistema caia, a tomada se desliga sozinha.

Exemplos práticos:

# Ligar a máquina no IP 192.168.1.100 $ make ligar ip=192.168.1.100 Ligando maquina em 192.168.1.100... OK — maquina ligada. # Desligar a máquina $ make desligar ip=192.168.1.100 Desligando maquina em 192.168.1.100... OK — maquina desligada. # Ligar por 45 minutos (desliga automaticamente) $ make ligar-com-timer ip=192.168.1.100 minutos=45 Ligando maquina em 192.168.1.100 por 45 minutos... OK — maquina ligada por 45 min. # Ver status atual $ make status-maquina ip=192.168.1.100

Fluxo Normal de Operação

1
Acesse a pasta do projeto no terminal:
cd /caminho/para/laundry-iot
2
Inicie o sistema:
make ligar-sistema
3
Acesse o painel no navegador: http://localhost:8000
Use o usuário admin (ou o configurado no arquivo .env).
4
Para parar o sistema ao final do dia ou manutenção:
make desligar-sistema

Solução de Problemas Comuns

SintomaCausa provávelSolução
Comando retorna "ERRO — nao foi possivel conectar" IP errado ou fora da rede Verifique o IP no roteador e se está na mesma rede Wi-Fi
Site não abre em localhost:8000 Containers parados Execute make ligar-sistema e verifique com make status-sistema
Máquina não desliga após o tempo Tarefa agendada parada Execute make reiniciar-sistema
Erro ao iniciar (port already in use) Porta 8000 em uso Pare o processo que usa a porta ou reinicie o servidor
